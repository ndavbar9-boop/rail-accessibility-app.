# ניהול נגישות רכבת — פרויקט Expo

הפרויקט הזה כולל את כל מה שצריך כדי לבנות קובץ APK אמיתי (לא רק להריץ ב-Expo Go), דרך שירות הבנייה בענן של Expo (EAS Build).

## מבנה הפרויקט
```
App.js              - קובץ האפליקציה (כל הקוד)
package.json        - רשימת החבילות
app.json            - שם האפליקציה, אייקון, מזהה חבילה (package name)
eas.json            - הגדרות בנייה (פרופיל "preview" מייצר APK להתקנה ישירה)
assets/             - אייקון, אייקון אדפטיבי (אנדרואיד), תמונת פתיח, פאביקון
```

## דרך א׳ — הכי פשוט בטלפון: GitHub + לוח הבקרה של Expo (דרך דפדפן בלבד)

1. פתח חשבון חינמי ב-GitHub (אם אין לך) והעלה את כל הקבצים בתיקייה הזו לריפו חדש.
   - אפשר להעלות קבצים ישירות דרך אתר/אפליקציית GitHub בלי מחשב ("Add file" → "Upload files").
2. פתח חשבון חינמי ב-https://expo.dev/signup
3. בלוח הבקרה של Expo: **Create a project** → חבר את ריפו ה-GitHub שיצרת.
4. לחץ על **Build** → בחר **Android** → פרופיל **preview** (זה מוגדר ב-`eas.json` להפיק APK, לא AAB).
5. המתן שהבנייה תסתיים (כמה דקות) — בסיום תקבל קישור להורדת קובץ ה-APK ישירות לטלפון.
6. פתח את הקובץ שהורדת כדי להתקין (יידרש לאשר "התקנה ממקורות לא ידועים" בהגדרות אנדרואיד בפעם הראשונה).

## דרך ב׳ — טרמינל בטלפון (אנדרואיד, עם אפליקציית Termux)

```bash
pkg install nodejs git -y
git clone <כתובת הריפו שלך>
cd <שם-התיקייה>
npm install
npx expo install --fix
npm install -g eas-cli
eas login
eas build -p android --profile preview
```
בסיום ה-CLI יציג קישור להורדת ה-APK.

## הערות חשובות

- **מזהה החבילה** (`android.package` ב-`app.json`) מוגדר כרגע ל-`com.railisrael.accessibility` כברירת מחדל זמנית — אפשר לשנות לכל מזהה ייחודי אחר (למשל `com.<שם_שלך>.railapp`), במיוחד אם בעתיד תרצו לפרסם בחנות Google Play.
- לפני הבנייה הראשונה מומלץ להריץ `npx expo install --fix` (או לבקש מ-Expo לעשות זאת דרך הלוח שלהם) כדי לוודא שכל גרסאות החבילות תואמות זו לזו.
- פרופיל `preview` ב-`eas.json` מייצר קובץ APK שניתן להתקנה ישירה על הטלפון (ללא Google Play). פרופיל `production` מייצר AAB המיועד להעלאה לחנות.
- ה-EAS Build עצמו רץ על שרתי Expo (בענן) — לא על הטלפון או המחשב — כך שאין צורך ב-Android Studio.
